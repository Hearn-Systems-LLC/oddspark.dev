# Acceptance Criteria

- The interface still has one button and no new fields; a domain remains optional.
- The same action produces a coherent general/local spark without a domain and a website-grounded spark with one.
- Every displayed result passes all coherence gates and lies within Hearn Systems' credible delivery envelope.
- A result never recommends duplicating a detected capability or casually replacing a helpful existing process.
- Website mode stays within the public-site evidence boundary; neither mode uses PII, cookies, sessions, Google reviews, or broader footprint research.
- Every result follows the result-card contract, names what remains unchanged, and expresses change level as a preliminary time range plus workflow-step impact.
- Before / After is qualitative unless the website supplies the numbers used.
- The CTA is specific to the spark, no-pressure, no-obligation, and oriented toward testing fit and finding the lowest-friction implementation.
- A result can be retold naturally and offers a novel but believable change to a recognizable routine.
