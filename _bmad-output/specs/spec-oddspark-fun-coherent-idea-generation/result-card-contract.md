# Result-Card Contract

Each result is a confident plan, not a hypothetical question, and contains these elements in order:

1. **Spark title** — a memorable name for the specific plan.
2. **The Plan** — the smallest useful version of the intervention in owner-understandable terms.
3. **Why It Fits** — the evidence or context behind the recommendation, including one restrained, charming website breadcrumb in domain mode. Research stays backstage; only one business-specific breadcrumb appears.
4. **What Gets Better** — the expected human or business improvement without unsupported numeric claims.
5. **Before / After** — a concise qualitative contrast between continuing the current routine and adopting the plan; numbers only when the public site supplies them.
6. **Change Level** — a clearly preliminary estimated implementation-time range plus the number of existing workflow steps that change and, where applicable, repetitive steps that disappear.
7. **What Stays the Same** — explicitly names preserved tools, decision authority, and untouched workflow steps.
8. **Implementation invitation** — tied to this exact spark and its smallest useful version; offers a bounded feasibility conversation with no price invented before discovery.

## CTA posture

"Talk through the problem, no pitch attached." Help test whether the idea fits, find the lowest-friction version, and say so if it is not worth changing. The desired action is asking Hearn Systems how the proposed solution could be implemented, but the experience remains problem-solving-led, no-pressure, and no-obligation.
