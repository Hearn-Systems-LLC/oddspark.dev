# Coherence Gates

Reject a candidate unless **all** are true:

1. **Recognizable routine** — begins from an observable or credible current behavior and a normalized recurring annoyance.
2. **Constructive intervention** — every friction leads to an imaginable solution; no fault-finding for its own sake.
3. **Capability inventory** — the core job is not already served by the site's existing tools. Existing tools are constraints or extension points, not targets for duplication.
4. **Channel fit** — the plan uses observed communication channels, unless it clearly and compellingly introduces a new one.
5. **Proportionality** — solution weight matches observable organizational scale, operational complexity, and likely maintenance capacity.
6. **Delivery fit** — Hearn Systems could credibly implement it through custom software, AI automation, integrations, data workflows, or adjacent digital systems.
7. **Preservation** — the plan retains every helpful tool, workflow step, and decision right it does not need to change.
8. **Natural retelling** — a person could explain the situation, fitting capability, and payoff naturally to a friend.
9. **Novel but imaginable** — goes beyond the most obvious idea while remaining concrete and approachable.

## Validation set (gate rejection tests)

Results must be validated against these representative contradictions; each must be rejected:

- Existing scheduler already serves the core job (fails gate 3).
- Channel mismatch (fails gate 4).
- Undersized or oversized solution (fails gate 5).
- Unactionable criticism (fails gate 2).
- Non-digital advice (fails gate 6).
