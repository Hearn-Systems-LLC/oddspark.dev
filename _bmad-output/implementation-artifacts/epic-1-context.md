## Goal

Deliver local-mode generation in production so one button press without a domain returns a committed, gate-passed Opportunity Brief or approved house Brief. Replace random-axis generation with a bounded, independently qualified pipeline while preserving the one-button experience and enabling local mode only after compatibility-first deployment and separate atomic activation.

## Requirements & Constraints

- Ground local Candidates in Blue Water Area context, date, seasonality, business situation, and the Delivery-Envelope capability bundle; exclude legacy random-axis vocabulary.
- Before one candidate-bound semantic judgment of all nine gates, tone, and claims, run deterministic schema, grounding, privacy, personal-name, and number-provenance checks. Unqualified results fail closed and rejected Candidates remain invisible.
- Share one six-call ledger and route-entry deadline. Start only complete generation-judge pairs; local mode permits at most three. Failure or exhaustion uses a curated gate-passing house Brief when authoritative commit is available.
- Render the closed, versioned eight-element Brief. Local output has no numeric ROI, percentages, savings, or pricing; effects are concrete and invitations are Spark-specific, pressure-free, and permit deciding against change.
- Qualify generation and judge independently without pooling primary/fallback evidence. Structural, semantic, and full-request evidence are separate; live metered runs require fresh exact approval and never run in CI.
- Preserve one button and one optional domain field. Before domain activation, domain requests stay domain-scoped but render effective local mode with fixed notice; scanning, EvidenceProvider use, global local projections, and permalinks are prohibited.
- COORD authoritatively claims, reads, commits, and counts served outcomes; KV is projection-only. Concurrent requests converge on one receipt, uncertainty returns 502 without rendering, and local artifacts expire non-sliding after 30 days.

## Technical Decisions

- Use immutable, single-pass Evidence, Generate, Local Gate, Judge, Commit, and Render stages; only the strike orchestrator retries.
- Keep one runtime-neutral pipeline under `src/pipeline/`, shared by Worker and Node verification, with infrastructure supplied through explicit ports.
- Use versioned canonical hashes. Adapters decode one complete value from the frozen location without extraction, repair, coercion, invention, or omission; reference mismatch rejects.
- The generation role is qualified primary-only from the approved Story 1.11 sole-member role set. Its fallback model leg remains unwired, no generation-fallback identity enters activation, and generation exhaustion or failure uses the approved deterministic house Brief path.
- COORD receipts hold a closed, versioned `CommittedBrief`; readers accept supported versions or an explicit lossless shim. Request scope owns cache and permalink eligibility; effective mode owns presentation.
- Explicit JSON acceptance wins representation selection; browser forms and HTML-capable requests receive shell HTML. Dynamic responses are non-cacheable; 400 and 502 outcomes are not served events.
- Activation atomically replaces one canonical manifest. Invalid or stale refs disable model roles. Assembly, reader deployment, inactive-writer deployment, and activation retain separate authority and rollback.
- Cloudflare Workers Builds auto-deploys its configured production branch, currently `develop`. Story work merges only to `develop`, Justin owns `develop` to `main`, and deployment preflight must verify the live build trigger before approval; any auto-deploying branch must remain within the approved release sequence.

## UX & Interaction Patterns

- Preserve the shell, breakpoints, one-button flow, and optional website field; the governed UX delta set is closed.
- Keep all eight elements ordered across representations. Domain-scoped results never get public permalinks.
- Suppress duplicate retries and use one status region. Enhanced results move focus once; full-document HTML does not. Errors and fallbacks remain inside the shell.
- Notices disclose causes without rejected ideas or retry detail. Avoid reproducibility claims before production proof. `/how` explains the pipeline, privacy, call cap, fallback, and non-determinism accessibly.

## Cross-Story Dependencies

Frozen contracts precede structural qualification; judge and generation evidence plus the semantic corpus precede semantic qualification; semantic qualification precedes full-request evidence and activation readiness. Release order is runtime assembly, compatibility reader, inactive writer, then separate local-only activation. Domain activation, production proof, receipt claims, receiver handoff, and legacy retirement remain later authorities.
