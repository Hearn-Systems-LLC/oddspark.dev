# Offline diagnosis — judge stage was excluded by the internal strike deadline

No provider call, adapter start, approval stamp, or frozen-byte change was made for this diagnosis.

## Root cause and exact path

The 120,000 ms qualification route ceiling is a harness-level observation and is not passed to the assembled strike orchestrator. `src/pipeline/assembly.mjs:40` hard-codes `STRIKE_DEADLINE_BUDGET_MS = 15000`; lines 240–248 construct the strike deadline as `startedMs + 15000` with `minimum_call_time_ms = 1000`.

1. Attempt 1 generated Candidate `24f7ac9a…` successfully in 9,114 ms. Because no provider judge call occurred and attempt 2 began 3 ms later, the normal continuing path is a deterministic Gate result `LOCAL_REJECTED` with `judge_calls === 0` (`strike.mjs:232`), which releases the reserved judge slot and continues. A judge-unqualified/invalid returned gate result with zero calls would instead break at lines 233–235, and a judge-admission failure would break at lines 197–204. One alternative cannot be excluded from the retained bytes: an unexpected throw inside `deps.gate` is caught at lines 212–216, counted internally as a judge-stage failure, and also continues without an instrumented provider call. Because the worker discarded the strike ledger and Candidate bytes, the first attempt's `LOCAL_REJECTED` versus `stage_failure` sub-classification is not independently recoverable. This uncertainty does not affect the exact second-attempt terminal below.
2. Attempt 2 was admitted at about 9.2 seconds because pair admission requires only two times the 1,000 ms minimum (`strike.mjs:164–170`), leaving roughly 5.8 seconds on the internal strike deadline. Its successful generation took 9,080 ms and finished about 18.3 seconds after the writer started—roughly 3.3 seconds after the 15-second strike deadline.
3. Immediately after generation, the judge-admission check at `strike.mjs:197–204` evaluated `deadline_ms - now < minimum_call_time_ms`, recorded `judge_not_admitted` with reason `deadline`, and broke before `deps.gate` or the judge provider could run.
4. House selection can occur after that break, but the pre-coordinator deadline check at `strike.mjs:257–259` returns `DEADLINE_EXCEEDED`. `assembly.mjs:266–267` converts any non-`ACCEPTED`/non-`HOUSE_ACCEPTED` strike result to the writer error. The qualification worker's outer catch then emits `pipeline_failed`, source `none`, with no commit or render.

The retained 101,718 ms is therefore irrelevant to judge admission: it is computed against the harness plan's 120-second route ceiling, while the real pipeline had already exhausted its separate 15-second strike deadline.

## Classification

Primary classification: **plan/schedule mismatch with the assembly's internal deadline contract**. The plan freezes a 120-second route ceiling and 19,833 ms provider timeout while expecting generation/judge pairs, but the unchanged assembly independently allows only 15 seconds for the entire strike. The providers succeeded and the orchestrator followed its coded fail-closed deadline logic; this is not a judge-provider failure and not evidence of incorrect deterministic Gate behavior.

Secondary classification: **harness observability bug**, not the cause of the stop. `worker.mjs:104–116` catches the writer error, discards the strike ledger/code, reconstructs every retained generation as `deterministic.pass: null` and `terminal: "provider_failed"`, even when `generation.success === true`. That mislabels both attempts and hides `LOCAL_REJECTED`, `judge_not_admitted(deadline)`, and `DEADLINE_EXCEEDED`, but it did not prevent the judge call.

## Minimal repair

To perform the intended 120-second full qualification rather than merely describe production's current 15-second behavior, the minimal safe functional repair is to make the assembly's strike deadline budget an explicitly validated injected value, defaulting to the existing 15,000 ms for production, and have only the qualification adapter bind it to `route_ceiling_ms - commit_reserve_ms` (119,000 ms). Do not simply replace the production constant globally. Add an offline test proving the default remains 15 seconds and the qualification override is closed, bounded, and leaves the commit reserve intact.

Separately, the minimal spike-only evidence repair is to retain the strike result code and ledger (or an equivalent stage-event callback) and derive deterministic/judge terminals from those bytes; a successful generation must never be labeled `provider_failed`. This observability repair is required for an independently articulate rerun but does not itself cause a judge call.

The functional deadline fix changes `src/pipeline/assembly.mjs`, so **it changes assembly bytes and requires a new runtime-assembly identity, re-freeze, plan regeneration, and fresh approval**. The secondary harness evidence repair changes only spike bytes and does not change the runtime assembly identity.
